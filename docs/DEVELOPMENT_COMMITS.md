# Suggested meaningful commit plan

The project snapshot includes the complete implementation. For coursework, do not fabricate a development history after the fact. If the instructor requires at least 8 real commits, the cleanest option is to start a new repository and make staged commits while implementing the files in these logical groups:
1. Initialize Maven project and domain model.
2. Add RouteStrategy interface and RoutePlanner context.
3. Implement Fastest and Cheapest strategies.
4. Implement Eco-Friendly and Balanced strategies.
5. Add hard constraints and no-suitable-route exception.
6. Add StrategySelector and runtime switching demo.
7. Add comparison service and fifth Safest strategy.
8. Add JUnit tests, UML diagrams, and README.

This document is explicit so the submission does not falsely claim that a retrospective commit history proves the original development process.
